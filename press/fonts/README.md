# Typography assets

Noto Sans variable is supplied as an optional, redistributable editorial font, not as a replacement for the approved wordmark. Source: [Google Fonts / Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans), retrieved 2026-10-10. Keep `OFL.txt` with copies. SHA-256: `bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.

The interface and supplied wordmarks use the system stack Helvetica Neue, Helvetica, Arial, sans-serif. These proprietary system fonts are not redistributed. The press wordmarks are outlined with the documentation-reference bold system font and spacing; they reproduce without installed fonts. Editable text-based originals remain in the project branding sources. Do not silently substitute a different wordmark font. Noto Sans is suitable for article copy and press captions. No font installation is required by the software.
