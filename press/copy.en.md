## Extended description

Aède is a music library engine written in Rust. It turns audio folders into a connected catalogue of albums, artists, tracks, credits and relationships. It runs locally through its command line and can expose an authenticated API for desktop clients. Incremental scanning; deterministic catalogue and attributed metadata; explicit external enrichment; Doctor diagnostics; accounts and private data; local HTTP or configured HTTPS server; playback, M3U exports and verified copying; FlacCompagnon analyses; presentation API for Phémios.

Aède owns the catalogue and domain rules; Phémios provides a desktop interface; FlacCompagnon supplies audio analysis tools. Their roles are complementary. The project favours a user-controlled library, explainable results and identified sources.
