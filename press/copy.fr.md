# Aède — Textes réutilisables

## Présentation courte

Aède est un moteur de bibliothèque musicale écrit en Rust. Il transforme les dossiers audio en catalogue relié : albums, artistes, pistes, crédits et relations. Il fonctionne localement en ligne de commande et peut exposer une API authentifiée pour les clients de bureau.

## Présentation développée

Aède est un moteur de bibliothèque musicale écrit en Rust. Il transforme les dossiers audio en catalogue relié : albums, artistes, pistes, crédits et relations. Il fonctionne localement en ligne de commande et peut exposer une API authentifiée pour les clients de bureau. Scan incrémental ; catalogue déterministe et métadonnées attribuées ; enrichissement externe explicite ; diagnostics Doctor ; comptes et données privées ; serveur HTTP local ou HTTPS configuré ; lecture, exports M3U et copie vérifiée ; analyses FlacCompagnon ; API de présentation pour Phémios.

Aède porte le catalogue et les règles métier ; Phémios propose une interface de bureau ; FlacCompagnon apporte les outils d’analyse audio. Leurs rôles sont complémentaires. Le projet privilégie une bibliothèque personnelle maîtrisée, des résultats explicables et des sources identifiées.
