# Aède press kit

Updated 2026-10-10. Start with `overview.fr.md` or `overview.en.md`; `copy.fr.md` and `copy.en.md` provide reusable short/extended descriptions. `brand-guide.md`, `logos/`, `fonts/` and `visuals/` contain editorial assets and their usage conditions.

Facts and captions are deliberately separated from release promises. No private account data, real music artwork or hidden achievement definitions are included. Do not publish developer machine paths, credentials or test-account details. Contact the project maintainer through the existing project channel; no unverified contact address is invented here.

Related projects: [Aède](https://craft-and-code.github.io/aede/) · [FlacCompagnon](https://craft-and-code.github.io/FlacCompagnon/).

Official source and issue tracker: [https://github.com/craft-and-code/aede](https://github.com/craft-and-code/aede).
