# Component explorer

Run `npm run components:dev` from `desktop/` and open `http://127.0.0.1:6007`. This reuses Phémios's isolated SolidJS Storybook tooling, on a different local port so both explorers can run together. `npm run components:check` type-checks and generates the static explorer under `dist-docs/components/`.

The catalogue covers the shared action control, loader, refresh feedback and form-height alignment. Refresh actions keep their arrow glyph rotating until the current turn finishes, including at least one 750 ms turn for a fast response. Results are not delayed, and the button remains disabled during that feedback. Reduced-motion preferences suppress rotation; a bounded fallback also releases the visual state when animation events are unavailable. The FastRefresh interaction checks an immediate result while feedback remains visible, followed by button re-enablement. Native application/account state is excluded from the explorer. The boundary refuses Tauri and application-state imports, publishes no general public directory and ignores environment files. Runtime acceptance belongs to the native application, not stories.

`npm run docs:ts` separately generates public TypeScript declarations and authored JSDoc comments under `dist-docs/frontend/`; Rustdoc is generated by the desktop gate. Neither document is a coverage percentage or a formal TSDoc conformance report.
