# Component explorer

Run `npm run components:dev` from `desktop/` and open `http://127.0.0.1:6007`. This reuses Phémios's isolated SolidJS Storybook tooling, on a different local port so both explorers can run together. `npm run components:check` type-checks and generates the static explorer under `dist-docs/components/`.

The first catalogue covers the shared action control, loader and form-height alignment. Native application/account state is excluded from the explorer. The boundary refuses Tauri and application-state imports, publishes no general public directory and ignores environment files. Runtime acceptance belongs to the native application, not stories.

`npm run docs:ts` separately generates public TypeScript declarations and authored JSDoc comments under `dist-docs/frontend/`; Rustdoc is generated by the desktop gate. Neither document is a coverage percentage or a formal TSDoc conformance report.
