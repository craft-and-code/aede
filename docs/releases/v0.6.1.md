## Aède 0.6.1

### Progressive integrity results

Authenticated album integrity tasks expose completed track results while the remaining files are checked. Cancellation retains completed evidence; partial results remain bounded, session-protected and excluded from public events. Diagnostic masking also covers JSON-escaped credentials. Audio files and their tags are never modified.

### Network playback for Phémios

The authenticated network-player API now supports OpenHome, Google Cast and SlimProto alongside UPnP, reusing the existing device engines. Cast requires explicit certificate fingerprint confirmation. Playback, discovery and cancellation retain the originating administrator session; logout, revocation, server shutdown and expired client leases stop owned playback. A foreign Cast session is never stopped during failed LOAD cleanup.

Physical receiver acceptance remains pending. AirPlay is not included. Clients must restart the updated engine to discover the new capabilities.

### CLI and desktop App

Choose an `aede-CLI-0.6.1-…` archive for terminal use or an `aede-App-0.6.1-…` installer for the local HTTPS server console. Downloads include SHA-256 checksums. The App retains its isolated data directory. FlacCompagnon core remains pinned to published 0.9.6.

The release workflow tests and builds native macOS Apple Silicon, Linux x86_64 and Windows x64 packages, then prepares a draft release. Builds are unsigned. The explicitly approved Linux GTK3 dependency exceptions remain documented in [desktop dependency findings](https://github.com/craft-and-code/aede/blob/v0.6.1/docs/coding/desktop-dependencies.md).
