## Aède 0.6.0

### A more useful desktop server console

The App now has dedicated status and request-log views, explicit log downloads and native copy controls for its HTTPS address, login and generated password. Music folders remain editable while the server runs; applying them still requires an explicit scan. Request summaries exclude credentials, query strings and concrete resource identifiers. Opening the server address in a browser displays connection guidance rather than a raw unknown-route error.

The interface contains trackpad gestures, keeps ordinary panel scrolling, refines its header and refresh feedback, and preserves native editing in inputs. Log storage is bounded and process-local; nothing is transmitted to a remote logging service.

### Composer albums and dynamic collections

Album projections expose exact local composer credits from editions, tracks, recordings and works. Clients can browse albums by composer and save those selections as private dynamic collections, without inferring composition credits from an album's principal artist. Update the executable and restart the server before synchronizing a client: scanning folders cannot add an API capability to an older running process.

### Separate CLI and App downloads

Choose an `aede-CLI-0.6.0-…` archive for terminal use or an `aede-App-0.6.0-…` installer for the local HTTPS console. Every download has a SHA-256 sidecar. The App keeps its own private library and administrator credentials, separate from ordinary CLI data and Phémios's embedded engine. Source audio and tags are unchanged. FlacCompagnon's shared analysis core remains pinned to published 0.9.6.

CLI builds retain their Rust 1.89 baseline; the independent desktop workspace requires Rust 1.90 or later. The release workflow builds/tests native macOS Apple Silicon, Linux x86_64 and Windows x64 artifacts and creates a draft for review. Builds are unsigned; physical audio and platform-specific manual acceptance retain the operating guides' documented limits.

The Linux desktop audit retains the explicitly reviewed GTK3 compatibility warnings documented in [desktop dependency findings](https://github.com/craft-and-code/aede/blob/v0.6.0/docs/coding/desktop-dependencies.md). These exceptions do not patch upstream dependencies.
