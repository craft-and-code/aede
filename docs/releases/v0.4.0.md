## What's new in v0.4.0

- The new Onde website brings together the CLI, local server, current DSP and future Phémios interface. French and English guides cover installation, all CLI commands, server routes and DSP stages, with interactive signal illustrations and links to Rustdoc and FlacCompagnon.
- A local HTTP/JSON/WebSocket server exposes catalog navigation and task activity. Scan and metadata-fetch jobs support polling and cancellation. On Unix, CLI writers can delegate to the running local server.
- Local playback supports native audio output, ReplayGain and Opus R128 normalization, bass/treble controls and a live spectrum display. Single-key transport controls work in Unix terminals and the native Windows console, with seeking, repeat and uniform/smart shuffle. Compatible tracks share processing state; native Vorbis decoding preserves independently verified playable frame bounds.
- Windows catalog paths preserve drive, network-share and verbatim spellings. Folder selection, album grouping, playlists and copying have dedicated regression coverage.

The server defaults to local access; accounts, explicitly configured HTTPS, authenticated native PCM playback and a Subsonic/OpenSubsonic adapter are implemented. Phémios and DSP Premium are planned projects, not included applications. Local writer delegation remains Unix-only. Native Windows console/output acceptance and physical gapless validation on hardware remain pending.
