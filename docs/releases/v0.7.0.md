## Aède 0.7.0

### Shared audio foundation

The release includes the shared `aede-audio` and `aede-dsp` crates used by Aède, Phémios and FlacCompagnon. They provide common decoding, PCM handoff, device playback and DSP primitives while leaving catalogue, account and server rules in Aède. Client build preparation can select this source after 0.7.0 is published as a stable release; a draft is not selected automatically.

### Safer catalogue and playback lifetimes

Catalogue refreshes, attributed metadata, analysis reports and private account state retain their source and owner boundaries. Offline scan paths and exclusions survive unavailable volumes; ambiguous aliases and oversized scan requests are refused before replacing retained data. Administrative MusicBrainz review exposes accept/reject/undo and exact-artist biography jobs through capability-checked APIs.

Playback and network-device operations retain the session and source that admitted them. Shutdown, logout, cancellation and deferred preparation cannot silently publish into a replacement session. Audio fixes preserve FLAC integrity results, saturate signed 24-bit output correctly and refuse unsupported low-rate loudness measurements. Physical renderer, gapless and digital-output acceptance remain separate from software tests.

### Desktop server maintenance

The App keeps Serveur, Statut and Journaux in the header. Its native maintenance actions open the App-owned data folder, generate a new administrator password while stopped, or select a new empty server profile while retaining the old data and archived configuration. Interrupted credential renewal remains recoverable. Live folder changes and scan cancellation preserve ownership and expose their actual outcomes.

### Website and dependency maintenance

The homepage uses the interactive Sillons animation and refreshed project statistics. Website build artifacts now expire after one day; CLI/App build artifacts retain their separate seven-day policy. Files attached to Releases are independent of those temporary artifacts.

Tokio is updated to 1.53.3 in both workspaces and the Windows clipboard dependency to 5.4.3. The remaining GLib unsoundness and `paste`/`proc-macro-error` maintenance findings stay documented and visible, with no new advisory exclusions. See the [dependency audit](https://github.com/craft-and-code/aede/blob/v0.7.0/docs/coding/dependency-audit.md) for the exact findings and remediation plan.

### Downloads and limits

Choose an `aede-CLI-0.7.0-…` archive for terminal use or an `aede-App-0.7.0-…` installer for the local HTTPS server console. The App keeps its own private data directory. FlacCompagnon core remains pinned to published 0.9.6. Audio files and their tags are never modified.

The release workflow tests and builds macOS Apple Silicon, Linux x86_64 and Windows x64 packages with SHA-256 sidecars, then creates a draft after every platform succeeds. Builds are unsigned. Native platform checks, real hardware interoperability and physical-output acceptance remain distinct from local software verification.
