## Aède 0.5.0

### A desktop server alongside the CLI

Choose a **CLI** archive for terminal use or an **App** installer for a local server console. The new SolidJS/Tauri application adds folders, starts the same Aède engine over loopback HTTPS, follows scans and exports a public connection profile for Phémios. Its profile and administrator credentials remain separate from existing CLI and Phémios installations. It does not install a background service or change audio files.

### Library and client follow-ups

The reviewed engine adds source-backed graph navigation, individual-track dynamic filters, private account data and the hardened server/playback contracts documented in the manual. FlacCompagnon's shared analysis core is pinned to published 0.9.6. Existing compatible data remains readable; unreadable private state is refused instead of reset.

### Packaging and verification

CLI and App downloads are named separately, with SHA-256 files. CLI builds retain their Rust 1.89 baseline; the independent desktop workspace uses Rust 1.90 or later. Builds are unsigned. Native CI covers macOS Apple Silicon, Linux x86_64 and Windows x64; physical audio, remote hosting and platform-specific manual acceptance retain the limits documented in the operating guides.
