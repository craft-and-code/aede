The sources command: what somebody else said about this library.

The catalog holds what the files say, the annotation file holds what you say, and sources.json holds what a source says — MusicBrainz first, a plugin later. This is the command that shows it, takes it in, and drops it.

It exists before anything fetches, on purpose. A store that can only be filled over the network can only be tested over the network, and the layer is worth more than that: --import reads a document in exactly the shape the file has, so the whole of it — attachment, agreement, removal — can be exercised offline, and so can a bug report.

The shape follows aede import, which does the same job for another tool’s analyses: --list says what is held, --forget removes it, --source narrows to one. Two stores of what somebody else said should not be learned twice.
