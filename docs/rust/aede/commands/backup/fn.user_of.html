What is in user.json, counting only what is in it.

The zeros are left out: “2 annotations, 0 collection, 0 record set aside” spends two thirds of a line saying nothing, and a reader checking that their notes are in the file has to find the one number that is not a zero. A store holding none of these does not exist on disk in the first place, so there is always something to say.
