Function left_out

fn left_out(rows: &[Absent<'_>], everything: bool)
Expand description

Says what this run held back, how much of it, and how to see it.

A filter the reader cannot see is a trap, and one they cannot turn off is only half an answer. The count is of the rows this run held back, so it falls with the name typed and cannot drift from the table above it; the way to see them is named in the same breath, because a report that says “some records are not shown” and stops there has told the reader they are missing something and left them no move.

The two reasons are named separately even though --all lifts both: one is this program’s editorial decision about what a wish list is for, the other is a decision the reader took themselves, and only the second has a listing of its own to undo it from.
