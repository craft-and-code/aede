Getting the catalog out: JSON, CSV, and playlists.

Three formats for three different questions.

JSON is the faithful dump: nine linked tables, one per table of the model, which is what allows the catalog to be rebuilt or fed to another program.

CSV is flat by nature, so it cannot hold that graph. It answers another question — “let me sort my library in a spreadsheet” — and for that a single denormalized table beats nine faithful ones. Its values are therefore raw: milliseconds and bytes, not 4:20 and 31.2 MB, because a column one cannot add up is a column one cannot use.

M3U is not an export of the catalog but of a selection: whatever is on screen, handed to a player.
