aede::commands::play::output

Module alsa

Source
Expand description

Direct ALSA integer output with an owned, nonblocking hardware PCM handle.

The software ring and the hardware buffer have separate clocks/counters. The worker never substitutes silence, recovers an xrun, or changes controls. Source admission and allocation finish before that worker is launched.
