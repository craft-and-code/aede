aede::commands

Source
Expand description

Copyable paths from one catalog page to the next.

A table naming related entities is informative; it becomes navigation only when it also says how to open them. These helpers keep that spelling in one place, prefer stable MusicBrainz identities where the command accepts one, and quote names so the printed command can be pasted into a shell safely.
