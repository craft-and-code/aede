Commands that can list what they hold rather than go and get more.

Not SAID_ELSEWHERE_COMMANDS, although it started as a copy of it. Those three options — --forget, --list, --source — happened to apply to the same three commands, and sharing one list made that coincidence look like a rule: fingerprint can list what it holds and has nothing to forget and no source to select. One list per question, not one list per set of commands that happen to agree today.
