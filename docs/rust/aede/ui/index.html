Expand description

Terminal presentation: colours, aligned tables, bars.

Two constraints guide this module. First, display width: an accented character takes several bytes but a single column, so aligning on len() would produce crooked tables. Then restraint: colours disappear as soon as the output is not a terminal, so that aede stats > file.txt stays readable.
