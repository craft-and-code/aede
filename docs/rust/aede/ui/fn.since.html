pub fn since(at: u64) -> String
Expand description

Pluralises a noun: plural(1, "album") → “1 album”.

Only the two endings the program actually uses are special-cased — -is becoming -es (analysis → analyses) and the sibilants that take -es. A full English pluraliser would be a library; “1 analysiss” is a typo the user reads every time. How long ago a moment was, in one short phrase.

Takes the moment, not the age, and that is the whole reason it exists beside ago. Ten call sites wrote ago(now_seconds() - at) and the eleventh wrote ago(at), which reads perfectly and says “56 years ago” for something that happened a second before — a Unix timestamp is a plausible number of seconds. A signature two callers can read two ways is a trap however well documented, so the arithmetic lives here, once.

The clock is read here rather than inside ago so that the part with rules in it stays a pure function of its argument, testable without a clock.
