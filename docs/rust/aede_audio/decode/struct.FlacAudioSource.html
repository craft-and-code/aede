Struct FlacAudioSource

pub struct FlacAudioSource { /* private fields */ }
Expand description

A seekable STREAMINFO-only native FLAC view followed by original audio bytes.

Optional metadata is skipped without parsing or allocating its bodies. The opened source is never modified, and reads retain its captured length.

pub fn probe(file: File) -> Result<Option<FlacProbe>, DecodeError>

Probe a regular opened file for native or Ogg FLAC without decoding audio.

Native FLAC uses the same metadata-free source as ordinary shared decoding, including scanned prefixes and contiguous leading ID3 blocks. Other format markers return None without constructing their reader. This supplies no PCM or MD5 verdict; the caller selects and configures its codec validator.

impl FlacAudioSource

pub fn new(file: File) -> Result<Option<Self>, DecodeError>

Inspect native metadata on the same opened regular file.

A leading ID3v2 block, including its optional footer, is skipped from its fixed-size header. None means its following bytes are not native FLAC. The resulting virtual file consists of fLaC, one final STREAMINFO block and original audio; it never changes the actual file or metadata.
