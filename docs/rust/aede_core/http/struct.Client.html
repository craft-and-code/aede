pub fn new(user_agent: impl Into<String>, interval: Duration) -> Client

A client for one service.

user_agent is not decoration: MusicBrainz requires a descriptive one carrying a way to contact whoever wrote the program, and throttles anonymous or generic callers as a single shared pool — so a library that sent ureq/3.4 would be sharing a rate limit with every other program that could not be bothered either. Build it with Client::identify.

pub fn get_json(&mut self, url: &str) -> Result<Json, Error>

Fetches a URL and parses the answer as JSON.

Blocks for as long as the rate requires before sending. That is the whole point: a caller that could forget to wait is a caller that will.

Source

pub fn get_bytes(&mut self, url: &str) -> Result<Vec<u8>, Error>

Fetches a URL and hands back the body as it came.

The one thing this client downloads that is not an answer to a question: an image. It waits its turn like everything else.

The size ceiling is the client library’s own — it refuses an oversized body rather than reading it — and the ceiling below is a second line behind it, checked on what actually arrived. Two guards rather than one because the first belongs to a dependency whose defaults may change, and the failure it prevents is a machine filling its memory from a wrong address.

Source

pub fn interval(&self) -> Duration

How long the next Client::get_json would wait before sending.

Exposed so a command can tell the user that asking about six hundred artists will take ten minutes before it starts, rather than leaving them to work it out from a progress line.
