One artist, as /ws/2/artist/{mbid}?fmt=json returns it.

A lookup, not a search, and the difference is the whole reason this exists beside artists. A search answers with an abbreviated entry and a relevance score, because it has to guess which artist was meant. A lookup is asked about one identifier and answers with the entity itself — life-span.ended and disambiguation among the fields a search result leaves out.

Which matters because a library tagged with Picard already carries those identifiers. Searching by name for an artist whose MBID sits in the tags is asking a question that has already been answered, and accepting a guess in place of a certainty.
