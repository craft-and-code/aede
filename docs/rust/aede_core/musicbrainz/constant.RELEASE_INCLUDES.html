What to ask for alongside a release, in one request.

A release is one edition; a release group is the album every edition of it belongs to. The two facts a library wants sit on opposite sides of that line — the label is the edition’s, the type and first release date are the album’s — and asking for them separately would be two requests per album at one request per second.

release-groups folds the album into the edition’s answer, so a library tagged by Picard, which writes the edition identifier, gets the whole record for the price of one lookup.
