Read-only coverage of MusicBrainz recording, work and edition credits.

A completed relationship lookup with no credits is an answer, not a gap. Count canonical recordings rather than file placements so reissues do not inflate the recording figures. Each local edition has its own lookup; manual edition corrections are counted without pretending it was queried.
