aede_core::playback

Module normalization

Source
Expand description

Selection of a playback gain from local audio metadata.

This module chooses a gain; aede-dsp applies it to decoded samples. The decoder must have applied the mandatory Opus ID header output gain before a selected R128 tag gain is applied.
