Struct ExactPcmSession

Source 
pub struct ExactPcmSession { /* private fields */ }
Expand description

A fixed-format source session with no modifying processing stages.

This is a software building block, separate from super::session::PcmSession. It owns no decoder, transport, sound device or listening records. The existing driver remains responsible for selection, cancellation/seeking, queue writes and history after accepted output. There are no gain, tone, rate conversion, downmix, guard, limiter or dither controls to silently apply or ignore here.

Call end_track only after successful decoder EOF, including a present FLAC MD5 verification. Each occurrence completes once, without delayed frames or flushing silence. Invalid blocks/lifecycle requests leave state unchanged. A transport interruption or output failure requires discarding this session and queued audio. Neither its output metadata nor produced completion markers establish device eligibility, audible completion or physical bit identity.
