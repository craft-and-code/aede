1//! The acoustic fingerprint of a file: what the audio *is*, not what it says.
2//!
3//! # Why this exists
4//!
5//! Every other identifier in this program comes out of the tags, and a badly
6//! tagged file therefore cannot be identified at all: `track03.mp3` with no
7//! title and no artist is invisible to MusicBrainz, because there is nothing
8//! to ask about. A fingerprint is computed from the **decoded audio**, so it
9//! answers for a file whose tags say nothing, and it disagrees with a file
10//! whose tags say the wrong thing.
11//!
12//! # It is computed, not fetched — and stored beside the checksum
13//!
14//! A fingerprint is Aède's own conclusion about the bytes, like
15//! [`crate::audit::integrity`] and unlike anything in `sources.json`: nobody
16//! told us, we worked it out. So it lives on [`crate::model::AudioFile`] and
17//! is carried across a rescan by the same size-and-mtime rule the integrity
18//! verdict uses. What **AcoustID** answers when shown one is a different
19//! thing entirely, and goes in the attributed layer where every other
20//! source's claim goes.
21//!
22//! # Two ways to compute one, and why ffmpeg comes first
23//!
24//! Chromaprint is the algorithm; there are two ordinary ways to run it.
25//!
26//! - **ffmpeg**, *when* it was built with `--enable-chromaprint`. Debian and
27//!   Ubuntu build it that way, so on those machines this is no new dependency
28//!   at all — Aède already requires ffmpeg for `spectrum` and
29//!   `copy --compress`.
30//! - **`fpcalc`**, the tool Chromaprint itself ships. Canonical, and the one
31//!   AcoustID's own documentation names.
32//!
33//! **Homebrew's ffmpeg does not have chromaprint**, which this module's first
34//! version claimed it did — a guess written as a fact, corrected by a reader
35//! pasting the `configuration:` line of a fresh `brew install ffmpeg`. On
36//! macOS the answer is `brew install chromaprint`, and it is a small package.
37//! The lesson is not about ffmpeg: **a build option is a property of somebody
38//! else's packaging decision, and this program has no business asserting one
39//! it has not seen.** So the availability check asks the muxer list rather
40//! than reading a version string, and the message names both ways out with
41//! the right one first for each platform.
42//!
43//! **The two agree, and that has been checked rather than assumed** — on one
44//! file, `ffmpeg -algorithm 1` and a bare `fpcalc` answer the same string, byte
45//! for byte. They agree only on those exact flags: `fpcalc -algorithm 1` is a
46//! *different* algorithm and answers something else — the measurement is beside
47//! the `ALGORITHM` constant below.
48//!
49//! ffmpeg is tried first because it is more likely to be there already; the
50//! fallback exists because "built with chromaprint" is not a promise anyone
51//! made. **Neither is linked or vendored**, exactly as ffmpeg is not: a
52//! checkout with neither installed builds, passes its tests, and says plainly
53//! what is missing.
54//!
55//! # The duration is part of the question
56//!
57//! AcoustID is asked for a fingerprint *and* a length, and refuses without
58//! both — the length is how it tells a full track from an excerpt that
59//! fingerprints alike. `fpcalc` prints it; ffmpeg's muxer does not, so the
60//! caller supplies it from the catalog, which read it out of the file's own
61//! header at scan time.
62
63use std::process::Command;
64
65/// What one file's audio amounts to, for a service that identifies audio.
66#[derive(Debug, Clone, PartialEq, Eq)]
67pub struct Fingerprint {
68    /// The base64 compressed fingerprint, as both tools emit it.
69    pub data: String,
70    /// The track's length in whole seconds, which the lookup also needs.
71    pub seconds: u32,
72}
73
74/// Which program produced a fingerprint, for a message to name.
75#[derive(Debug, Clone, Copy, PartialEq, Eq)]
76pub enum By {
77    /// ffmpeg's `chromaprint` muxer.
78    Ffmpeg,
79    /// Chromaprint's own `fpcalc`.
80    Fpcalc,
81}
82
83impl By {
84    /// The program's name, as somebody would type it.
85    pub fn program(self) -> &'static str {
86        match self {
87            By::Ffmpeg => "ffmpeg",
88            By::Fpcalc => "fpcalc",
89        }
90    }
91}

93/// The algorithm AcoustID's index is built on.
94///
95/// Chromaprint has three, and a fingerprint computed with the wrong one is not
96/// wrong-looking — it is a valid fingerprint that matches nothing, which is
97/// indistinguishable from a recording nobody has ever submitted. `fpcalc`
98/// defaults to it; ffmpeg's muxer numbers the same list from zero, so the
99/// second entry is the one, and it is passed explicitly rather than trusted to
100/// stay the default.
101///
102/// **The two programs number the list differently, and it is measured rather
103/// than assumed.** On one file, ffmpeg 1.5.1 and fpcalc 1.5.1:
104///
105/// ```text
106/// ffmpeg -algorithm 1  AQAAS0mUaEkSRZEAAA…   ← what Aède computes
107/// fpcalc               AQAAS0mUaEkSRZEAAA…   ← identical, its default
108/// fpcalc -algorithm 1  AAAAS4kUSUqSJEkWAA…   ← a different algorithm
109/// ffmpeg -algorithm 2  AgAADUmUaEkSRZEAAA…
110/// ```
111///
112/// So ffmpeg's number *is* the version byte the fingerprint begins with, and
113/// fpcalc's is that plus one. Aède's ffmpeg path passes `1` and its fpcalc path
114/// passes **nothing**, and the two therefore agree — which is the whole premise
115/// of having two paths at all. Anything that tells a reader to compare with
116/// `fpcalc` must not tell them to add `-algorithm 1`.
117const ALGORITHM: &str = "1";
118
119/// Whether either program is available, and which.
120///
121/// Looked for once per run by the caller, never once per file: a thousand
122/// tracks would otherwise mean a thousand failed lookups before the first
123/// fingerprint. The same reasoning, and the same shape, as
124/// [`crate::ffmpeg::find`].
125pub fn find() -> Option<By> {
126    if has_chromaprint() {
127        return Some(By::Ffmpeg);
128    }
129    has_fpcalc().then_some(By::Fpcalc)
130}
131
132/// `true` when Chromaprint's own `fpcalc` is on the path.
133///
134/// Split out of [`find`] so that a test can ask the question without being told
135/// the answer `find` prefers: it returns ffmpeg whenever ffmpeg will do, which
136/// is right for a run and useless to a test whose whole subject is whether the
137/// two agree.
138fn has_fpcalc() -> bool {
139    Command::new("fpcalc")
140        .arg("-version")
141        .stdout(std::process::Stdio::null())
142        .stderr(std::process::Stdio::null())
143        .status()
144        .is_ok_and(|status| status.success())
145}
146
147/// `true` when the ffmpeg on this machine can produce a fingerprint.
148///
149/// Asked of its muxer list rather than of its version string: a build says
150/// `--enable-chromaprint` in its configuration line only when it was compiled
151/// from source with that flag showing, while the muxer list is what it can
152/// actually do.
153fn has_chromaprint() -> bool {
154    let Some(ffmpeg) = crate::ffmpeg::find() else {
155        return false;
156    };
157    Command::new(ffmpeg)
158        .args(["-hide_banner", "-muxers"])
159        .output()
160        .is_ok_and(|out| String::from_utf8_lossy(&out.stdout).contains("chromaprint"))
161}
162
163/// Computes the fingerprint of one file.
164///
165/// `seconds` is the length the catalog holds, used only on the ffmpeg path,
166/// which emits no duration of its own. `fpcalc` states one and its answer
167/// wins: it measured what it actually decoded, and a header that disagrees
168/// with the stream is exactly the kind of file this whole feature exists for.
169///
170/// The path must resolve to a regular local file. It is canonicalized before
171/// invoking either helper, so relative names cannot become options or URLs.
172/// Directories, devices and other special files are refused before a helper
173/// can block reading them.
174pub fn of(by: By, path: &std::path::Path, seconds: u32) -> Result<Fingerprint, String> {
175    let path = local_file(path)?;
176    match by {
177        By::Ffmpeg => {
178            let ffmpeg = crate::ffmpeg::find().ok_or_else(|| "ffmpeg is gone".to_string())?;
179            let out = Command::new(ffmpeg)
180                .args(["-hide_banner", "-loglevel", "error", "-i"])
181                .arg(&path)
182                .args(["-f", "chromaprint", "-fp_format", "base64"])
183                .args(["-algorithm", ALGORITHM])
184                .arg("-")
185                .output()
186                .map_err(|e| format!("ffmpeg could not be run: {e}"))?;
187            if !out.status.success() {
188                return Err(said(&out.stderr));
189            }
190            read_ffmpeg(&String::from_utf8_lossy(&out.stdout), seconds)
191        }
192        By::Fpcalc => {
193            let out = Command::new("fpcalc")
194                .arg(&path)
195                .output()
196                .map_err(|e| format!("fpcalc could not be run: {e}"))?;
197            if !out.status.success() {
198                return Err(said(&out.stderr));
199            }
200            read_fpcalc(&String::from_utf8_lossy(&out.stdout))
201        }
202    }
203}
204
205fn local_file(path: &std::path::Path) -> Result<std::path::PathBuf, String> {
206    let fail = |detail: &dyn std::fmt::Display| {
207        format!(
208            "a local regular file is required for fingerprinting: {}: {detail}",
209            path.display()
210        )
211    };
212    let resolved = std::fs::canonicalize(path).map_err(|error| fail(&error))?;
213    crate::copy::validate_source(&resolved).map_err(|error| fail(&error))?;
214    Ok(resolved)
215}

217/// The last thing a failed program said, for a message worth reading.
218fn said(stderr: &[u8]) -> String {
219    let text = String::from_utf8_lossy(stderr);
220    text.lines()
221        .rfind(|line| !line.trim().is_empty())
222        .unwrap_or("it failed without saying why")
223        .to_string()
224}

226/// Reads what ffmpeg's chromaprint muxer wrote to its output.
227///
228/// Split out so the parsing is tested without running anything: the muxer
229/// writes the base64 fingerprint and nothing else, and the empty answer — a
230/// file too short to fingerprint, or one that decoded to silence — has to be
231/// a refusal rather than an empty fingerprint sent to a service that would
232/// match it against everything.
233pub fn read_ffmpeg(stdout: &str, seconds: u32) -> Result<Fingerprint, String> {
234    let data = stdout.trim().to_string();
235    usable(data, seconds)
236}
237
238/// Reads `fpcalc`'s two lines: `DURATION=` and `FINGERPRINT=`.
239///
240/// The duration it states is preferred over the caller's, because it is the
241/// length of what was decoded rather than the length a header claims.
242/// Decimal fractions are truncated to whole seconds; malformed fractions,
243/// signs and values outside `u32` are refused instead of accepting a prefix.
244pub fn read_fpcalc(stdout: &str) -> Result<Fingerprint, String> {
245    let mut data = String::new();
246    let mut seconds = 0u32;
247    for line in stdout.lines() {
248        match line.split_once('=') {
249            Some(("FINGERPRINT", value)) => data = value.trim().to_string(),
250            Some(("DURATION", value)) => {
251                seconds = parse_seconds(value.trim())?;
252            }
253            _ => {}
254        }
255    }
256    usable(data, seconds)
257}
258
259fn parse_seconds(value: &str) -> Result<u32, String> {
260    let (whole, fraction) = value
261        .split_once('.')
262        .map_or((value, None), |(whole, fraction)| (whole, Some(fraction)));
263    if whole.is_empty()
264        || !whole.bytes().all(|byte| byte.is_ascii_digit())
265        || fraction
266            .is_some_and(|part| part.is_empty() || !part.bytes().all(|byte| byte.is_ascii_digit()))
267    {
268        return Err("fpcalc returned an invalid duration".to_string());
269    }
270    whole
271        .parse()
272        .map_err(|_| "fpcalc returned a duration outside the supported range".to_string())
273}

275/// The one gate both readers pass through.
276///
277/// An empty fingerprint and a zero length are each refused, because either
278/// makes a lookup that cannot mean anything: AcoustID needs both, and sending
279/// a blank one asks the service to match silence against its whole index.
280fn usable(data: String, seconds: u32) -> Result<Fingerprint, String> {
281    if data.is_empty() {
282        return Err("no fingerprint came back: the audio may be too short".to_string());
283    }
284    if seconds == 0 {
285        return Err("no duration is known for this file, and a lookup needs one".to_string());
286    }
287    Ok(Fingerprint { data, seconds })
288}

290/// What to tell somebody who has neither program, worded so they can act.
291///
292/// Both ways out are named, and which one is likelier is said, because "no
293/// fingerprinting tool was found" leaves a reader to guess that ffmpeg — which
294/// they already have for the spectrograms — might be the answer.
295pub fn missing() -> String {
296    "\
297Fingerprinting needs Chromaprint, and no way to run it was found.
298
299Two programs can do it, and Aède ships neither.
300
301  macOS      brew install chromaprint
302             Homebrew's ffmpeg is built without chromaprint, so the ffmpeg
303             you already have for the spectrograms cannot do this one.
304
305  Debian     apt install ffmpeg
306  Ubuntu     — theirs is built with chromaprint, so this is enough. Failing
307             that, apt install libchromaprint-tools.
308
309Everything else in Aède works without either. Run \"aede fingerprint\" again
310once one of them is on your PATH."
311        .to_string()
312}
