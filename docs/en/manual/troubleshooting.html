CLI — Commands⌄

Preserve and administer

  • accounts Manage local accounts
  • serve Serve the local HTTP/JSON/WebSocket catalog API and coordinate CLI writes
  • cancel Request cancellation of a delegated scan or fetch on the local server
  • check Verify the checksums stored in audio containers
  • reset Remove the catalog snapshot, including watched roots, while keeping separate stores
  • backup Save the catalog, sources, and personal data together
  • restore Restore a previously saved Aède backup
  • rules List, export, or import reproducible personal decisions
  • help Show the command index or the page for one command

Build and inspect

  • scan Read watched music folders into the local catalog
  • roots List, add, remove, or exclude watched folders
  • stats Show the library's size, quality, and completeness
  • doctor Find missing metadata, duplicates, and other catalog issues
  • file Inspect one audio file directly, without the catalog

Enrich and correct

  • analyze Analyze albums with FlacCompagnon and optionally save one JSON report per album
  • credits Measure recording, work and edition credit coverage
  • credit Add a manual credit or exclude/restore one sourced credit without touching tags
  • spectrum Create spectrograms beside the selected music
  • import Import acoustic analyses from FlacCompagnon
  • sources Inspect, export, import, or remove externally sourced data
  • review Resolve uncertain or conflicting source identities without changing tags
  • fetch Enrich artists, albums, tracks, and artwork from chosen sources
  • missing List credited studio albums that the local shelf does not hold
  • merge Record that two local artist spellings name one person
  • extract Write artwork already embedded in audio files beside the music
  • fingerprint Compute acoustic fingerprints without using the network

Find and select

  • copy Copy a selection to a player, card, or other destination
  • playlist Write portable playlists in album and artist folders
  • play Play local music
  • query Select tracks with the relational query language
  • collection Save, run, or remove a named dynamic collection
  • collections List the saved dynamic collections
  • search Search graph objects and source-only contributors, plus optional notes, comments, or lyrics
  • export Export the catalog as JSON or a table

Browse the catalog

  • relations List local and sourced graph relationships with stable IDs
  • relation Inspect, annotate, or label one graph relationship
  • artists List artists in the catalog
  • countries Summarize artists by their MusicBrainz origin
  • albums List albums in the catalog
  • genres List genres in the catalog
  • genre Show albums and artists carrying one genre
  • labels List record labels in the catalog
  • label Show a label's catalog and artists; check a Discogs profile when needed
  • years Break the catalog down by release year
  • artist Show a local artist or a source-only credited contributor and their links
  • album Show one album's tracks, credits, and sources
  • track Show a track's album, credits, tags, and technical facts
  • recording Show one recording, its local placements, and sourced work links
  • work Show one composition and the recordings that realize it
  • release-group Show the album identity shared by every local edition

Personalise

  • love Mark an artist, album, or track as a favourite
  • rate Give an artist, album, or track a personal rating
  • note Read or write a personal note
  • tag Attach or remove personal labels
  • played Manually record a listen made outside Aède, or undo its latest record with --remove
  • favourites List everything marked as a favourite
  • notes List, export, or import personal notes
  • history Show listening history, newest first

Troubleshooting

Recognize common setup, selection, filesystem, fetch and playback errors.

Read the full error first: Aède refuses unsupported arguments/options instead of silently ignoring them. Most remedies preserve original files. Use aede help COMMAND for the actual executable’s version and options.

The command is not found#

Run ./aede from the extracted folder on macOS/Linux or .\aede.exe in PowerShell. Otherwise put its directory on PATH and open a new terminal. PATH locates executables; --data locates the catalog. These are different settings.

No catalog / empty library#

Run aede scan "/path/to/music" with the same --data as the failing command. --data never scans music. Check roots, stats and read permissions. Folder names with spaces need quotes. Do not solve a wrong-data-folder problem by deleting the real user store.

A watched drive is unplugged#

Reconnect it before scan. Aède refuses rather than forgetting every absent track. If you deliberately stop using it, roots --remove FOLDER updates the watched list; read the immediate-rescan behavior and use --no-scan if appropriate. A reset deletes watched roots and requires naming them again.

An option/name is rejected#

Plural albums/artists list; singular album TITLE/artist NAME open. Put positional title before a name-valued option: track "So What" --artist "Miles Davis". Use one export format, and add --csv for --separator/export --tracks. --limit=0 is invalid; use --all when offered. Unknown entity terms in a query can be errors, distinct from a valid query with no matching tracks.

Copy/download cannot write#

Check free space and permissions at the destination. copy refuses paths overlapping your library. Sidecar downloads require a filesystem supporting hard links for atomic non-overwriting publication; FAT/exFAT does not satisfy that requirement. Do not bypass it by overwriting originals. --dry-run previews work but can still validate required tools.

Metadata is missing after fetch#

Use the right pass: lyrics require --lyrics, discographies --discography, credits --credits. Inspect sources --list, review and credits for pending/untrusted/empty/unidentified distinctions. Existing completed answers are reused; --full asks again intentionally. Service keys must be available in the process actually doing the work, including the server when delegated. Do not paste keys into an issue.

Playback tool/device failure#

Check FFmpeg/ffplay in the same terminal’s PATH. Linux release archives require ffplay. Format tag support does not imply native decoder support. Unknown multichannel layouts are refused; known layouts can downmix to stereo without LFE. Windows keyboard transport is not implemented. Device interruptions/underruns can remain audible despite correct file decoding; the project has not measured physical gapless behavior on all devices. Read the active DSP stage report before interpreting a lower level as a file defect.

Ctrl-C did not stop scan/fetch#

If the Unix server accepted a delegated task, closing the CLI does not cancel it. Use cancel TASK_ID with the same data directory; saved fetch answers remain. HTTP jobs use the administrative cancellation route. If the server restarted, old in-memory task IDs expire.

Recover or report a defect#

Keep the data directory and make a backup before recovery. Stop the server for a production restore and rehearse in a separate directory. For a bug report include executable version, operating system, redacted command/error and a minimal safe reproduction. Avoid publishing private music paths, notes, service secrets or full personal-store dumps. See data safety and backup.
