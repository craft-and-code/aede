  • accounts Manage local accounts
  • serve Serve the local HTTP/JSON/WebSocket catalog API and coordinate CLI writes
  • cancel Request cancellation of a delegated scan or fetch on the local server
  • check Verify the checksums stored in audio containers
  • reset Remove the catalog snapshot, including watched roots, while keeping separate stores
  • backup Save the catalog, sources, and personal data together
  • restore Restore a previously saved Aède backup
  • rules List, export, or import reproducible personal decisions
  • help Show the command index or the page for one command

Build and inspect

  • scan Read watched music folders into the local catalog
  • roots List, add, remove, or exclude watched folders
  • stats Show the library's size, quality, and completeness
  • doctor Find missing metadata, duplicates, and other catalog issues
  • file Inspect one audio file directly, without the catalog

Enrich and correct

  • analyze Analyze albums with FlacCompagnon and optionally save one JSON report per album
  • credits Measure recording, work and edition credit coverage
  • credit Add a manual credit or exclude/restore one sourced credit without touching tags
  • spectrum Create spectrograms beside the selected music
  • import Import acoustic analyses from FlacCompagnon
  • sources Inspect, export, import, or remove externally sourced data
  • review Resolve uncertain or conflicting source identities without changing tags
  • fetch Enrich artists, albums, tracks, and artwork from chosen sources
  • missing List credited studio albums that the local shelf does not hold
  • merge Record that two local artist spellings name one person
  • extract Write artwork already embedded in audio files beside the music
  • fingerprint Compute acoustic fingerprints without using the network

Find and select

  • copy Copy a selection to a player, card, or other destination
  • playlist Write portable playlists in album and artist folders
  • play Play local music
  • query Select tracks with the relational query language
  • collection Save, run, or remove a named dynamic collection
  • collections List the saved dynamic collections
  • search Search graph objects and source-only contributors, plus optional notes, comments, or lyrics
  • export Export the catalog as JSON or a table

  • relations List local and sourced graph relationships with stable IDs
  • relation Inspect, annotate, or label one graph relationship
  • artists List artists in the catalog
  • countries Summarize artists by their MusicBrainz origin
  • albums List albums in the catalog
  • genres List genres in the catalog
  • genre Show albums and artists carrying one genre
  • labels List record labels in the catalog
  • label Show a label's catalog and artists; check a Discogs profile when needed
  • years Break the catalog down by release year
  • artist Show a local artist or a source-only credited contributor and their links
  • album Show one album's tracks, credits, and sources
  • track Show a track's album, credits, tags, and technical facts

  • work Show one composition and the recordings that realize it

  • note Read or write a personal note

  • favourites List everything marked as a favourite

DSP — Audio

Output and diagnostics

Backends, submitted peaks, unknown true peak, shortages and drain limits.

The sound you hear includes Aède's processing, the output backend, the operating system and the device. Diagnostics identify the part Aède can observe rather than calling the whole path transparent or bit-perfect.

Native output and fallback#

aede play uses native CPAL when a compatible channel/sample format is available, preferring floating point. Otherwise it uses ffplay. Opus and M4A decoding also require FFmpeg. To explicitly choose a backend for a command:

AEDE_AUDIO_BACKEND=native aede play /path/to/song.flac
AEDE_AUDIO_BACKEND=ffplay aede play /path/to/song.flac

native requires that route rather than silently falling back; ffplay must be installed for its route. Aède sends processed f32le blocks to ffplay. The native path receives processed samples through a preallocated frame-aligned ring; its Aède callback does not allocate, lock or log. It can still have queue shortages or host errors. Aède records listens asynchronously so history writes do not block the decode loop.

Read the stage report#

Look for source/output sample rate and channel information, backend/format, normalization source and selected gain, the normalization headroom reserve, optional tone stage/reserve and rate conversion where active. A disabled stage differs from a stage unavailable because the format/path does not support it. The CLI reports that dynamic gain reduction is unavailable without a limiter; it does not invent a limiter meter from the hard guard.

Output peak snapshot#

The output meter observes complete guarded PCM submitted to the sink. It reports submitted frames, sample peak before/after the guard, an oversampled true-peak estimate when available, and the number of samples changed by the guard. A sample peak of 1 corresponds to 0 dBFS; smaller amplitudes are below full scale. Unknown/unavailable true peak must not be read as zero.

At 192 kHz and above, true peak is unknown because the current meter no longer oversamples. Meter failure can also make it unavailable. Incomplete output-span statistics are explicitly unavailable rather than claimed complete. Measurements precede native dither/device conversion and do not measure physical sound. Source loudness is measured separately before processing.

Shortages, host errors and drain#

Consumed-frame counters, bounded queue occupancy, queue shortages and host xruns distinguish late decoded data from driver scheduling/output problems. An underrun means the output needs samples before they arrive; exact silence may be emitted. Not every recoverable route/scheduling notification is a fatal error, but it remains visible as a warning.

Final drain and output-format changes keep transport controls usable. Native drain treats five seconds without consumed-frame progress as an error. The approximately 100 ms host allowance is counted in active time, not while paused, and is not a physical playback acknowledgement. These limits do not certify latency, seamless joins or NAS performance.

If playback fails, keep its diagnostic message, verify backend dependencies and file/layout compatibility, and compare with flat tone/normalization off. Do not delete original files or data stores to repair an audio-device error. Continuity separates tested PCM joins from unmeasured physical playback.
