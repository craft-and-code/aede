CLI — Commands⌄

Preserve and administer

  • accounts Manage local accounts
  • serve Serve the local HTTP/JSON/WebSocket catalog API and coordinate CLI writes
  • cancel Request cancellation of a delegated scan or fetch on the local server
  • check Verify the checksums stored in audio containers
  • reset Remove the catalog snapshot, including watched roots, while keeping separate stores
  • backup Save the catalog, sources, and personal data together
  • restore Restore a previously saved Aède backup
  • rules List, export, or import reproducible personal decisions
  • help Show the command index or the page for one command

Build and inspect

  • scan Read watched music folders into the local catalog
  • roots List, add, remove, or exclude watched folders
  • stats Show the library's size, quality, and completeness
  • doctor Find missing metadata, duplicates, and other catalog issues
  • file Inspect one audio file directly, without the catalog

Enrich and correct

  • analyze Analyze albums with FlacCompagnon and optionally save one JSON report per album
  • credits Measure recording, work and edition credit coverage
  • credit Add a manual credit or exclude/restore one sourced credit without touching tags
  • spectrum Create spectrograms beside the selected music
  • import Import acoustic analyses from FlacCompagnon
  • sources Inspect, export, import, or remove externally sourced data
  • review Resolve uncertain or conflicting source identities without changing tags
  • fetch Enrich artists, albums, tracks, and artwork from chosen sources
  • missing List credited studio albums that the local shelf does not hold
  • merge Record that two local artist spellings name one person
  • extract Write artwork already embedded in audio files beside the music
  • fingerprint Compute acoustic fingerprints without using the network

Find and select

  • copy Copy a selection to a player, card, or other destination
  • playlist Write portable playlists in album and artist folders
  • play Play local music
  • query Select tracks with the relational query language
  • collection Save, run, or remove a named dynamic collection
  • collections List the saved dynamic collections
  • search Search graph objects and source-only contributors, plus optional notes, comments, or lyrics
  • export Export the catalog as JSON or a table

Browse the catalog

  • relations List local and sourced graph relationships with stable IDs
  • relation Inspect, annotate, or label one graph relationship
  • artists List artists in the catalog
  • countries Summarize artists by their MusicBrainz origin
  • albums List albums in the catalog
  • genres List genres in the catalog
  • genre Show albums and artists carrying one genre
  • labels List record labels in the catalog
  • label Show a label's catalog and artists; check a Discogs profile when needed
  • years Break the catalog down by release year
  • artist Show a local artist or a source-only credited contributor and their links
  • album Show one album's tracks, credits, and sources
  • track Show a track's album, credits, tags, and technical facts
  • recording Show one recording, its local placements, and sourced work links
  • work Show one composition and the recordings that realize it
  • release-group Show the album identity shared by every local edition

Personalise

  • love Mark an artist, album, or track as a favourite
  • rate Give an artist, album, or track a personal rating
  • note Read or write a personal note
  • tag Attach or remove personal labels
  • played Manually record a listen made outside Aède, or undo its latest record with --remove
  • favourites List everything marked as a favourite
  • notes List, export, or import personal notes
  • history Show listening history, newest first

Options, syntax and output

Shared options, command-scoped families and the complete option matrix.

An option changes one command’s behavior. Aède separates true shared options from reusable command-scoped families and specialized flags. Never assume that a familiar option applies everywhere: the command’s own table is the practical reference.

Shared presentation and data options#

OptionMeaning
--data FOLDERUse this Aède data directory, not a music folder to scan. Applies wherever the operation reads/writes stored data.
--no-colorDisable terminal ANSI colors.
--help, -hShow index or current command help and stop.
--version, -v, -VPrint executable version and stop.

Data precedence is --data, AEDE_HOME, $XDG_DATA_HOME/aede, ~/.local/share/aede, then .aede in the working folder if HOME is unset. A direct file inspection needs no catalog; playback still uses the data directory for catalog selections/history. Use one location consistently with the server.

How to type values#

aede albums --limit 10
aede albums --limit=10
aede track "So What" --artist "Miles Davis"
aede play "/path/to/audio.flac" --bass -2
aede note album "Kind of Blue" --file -
aede file -- ./-track.flac

Both --option value and --option=value work. Paths/numbers/keywords take one token. Name-valued options (--artist, --album, --with, --genre, --label, --comment, --role, --country, --text, --from, --tag, --query, --collection, --instrument) consume words until the next option: put the positional name first. Quote multiword paths and names to make boundaries explicit. -- ends option parsing for a path starting with a dash. A lone - is accepted as standard input for notes. --bass -2/--treble -2 specially accept a negative numeric value; --bass=-2 also works.

Short forms are separate options: -j means command-scoped --json, -o FILE means command-scoped --output FILE. -o=FILE is supported. Do not combine short letters (-jo); that is not a declared alias. Unknown/missing-valued options are validated even before help/version. Repeating the same option currently keeps the last value; write it once to avoid accidental replacement.

Reusable families#

Pagination: --limit N, --offset N, --all only on the commands below. N is a whole number; limit must be positive, offset starts at zero, all and limit are incompatible. Ordinary paged lists generally default to 50; some reports choose smaller subsidiary lists. Export preserves the actual filtered/paged rows, so request all deliberately.

Output: choose one of CSV, JSON or M3U where supported. --output/-o writes a real export, not arbitrary human pages. --separator requires CSV; export --tracks requires CSV. CSV uses RFC-compatible quoting; tools that split blindly on commas can corrupt quoted titles. --separator tab avoids that for simple tab-delimited shell workflows. M3U contains file paths and does not copy sound.

Export destinations are checked before a command changes personal data. Active Aède stores and writer locks, existing audio files, symbolic links and non-regular targets are refused. An ordinary report is replaced atomically after its full content is written; missing report folders may be created. Human terminal output escapes control instructions in notes, paths and metadata. JSON/CSV exports preserve original values; treat CSV text as untrusted data when opening it in a spreadsheet.

Confirmation: --yes exists only for reset, history, fetch, backup and restore. It skips that command’s actual confirmation; it is not a universal “ignore errors” option. Without a terminal, a needed confirmation refuses unless deliberately accepted.

Work reuse: --full belongs to scan/check/spectrum/fetch/fingerprint with different meanings; analyze uses --force. Never infer behavior from the name alone.

Complete recognized-option matrix#

This inventory follows the current dispatcher and handlers. It lists accepted command scope, not a promise that every combination is valid. Specialized constraints are documented per command. Current known handler gaps: missing --source and merge --source are accepted but not applied; sources --source filters list/forget and selects template provenance, while summary/export currently include every source. --compress/--quality belong semantically to copy although the current dispatcher does not reject those recognized names on every unrelated command.
